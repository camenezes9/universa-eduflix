# Universo Educa Mais

PROMPT PARA LOVABLE - UNIVERSO EDUCA+

Tipo de Projeto: Website Enterprise para Instituição de Ensino

Objetivo: Criar um site profissional e atraente para escola de cursos profissionalizantes com foco em conversão e engajamento de alunos.

ESTRUTURA E LAYOUT:

Design Enterprise estilo Buffallos com as seguintes características:

Layout moderno, limpo e profissional

Paleta de cores baseada na logo: Azul marinho (#1B3B6F), Laranja vibrante (#FF6B35), Branco e tons de cinza claro

Tipografia moderna e legível (Montserrat ou Poppins para títulos, Open Sans para texto)

Design responsivo (mobile-first)

Animações suaves e transições elegantes

Cards com sombras sutis e bordas arredondadas

Botões com gradientes e hover effects
